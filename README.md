# Diabetes Patient Health Analytics — Excel Dashboard

## Overview
An interactive healthcare analytics dashboard built in Microsoft Excel to analyze 
2,335+ patient records across diabetes, heart disease, cancer, BMI, and hospital 
tier charges using Power Query, Power Pivot, and Pivot Charts.

## Key Metrics
- Total Charges: $31,592,358
- Average BMI: 30.97
- Cancer Cases: 2,335
- Heart Disease Cases: 2,335
- Average HBA1C: 6.58

## Dashboard Features
- Age-wise cancer and heart patient trend analysis
- Smoker vs non-smoker average charge comparison
- Weight category wise heart patient distribution (Obesity, Overweight, Healthy, Underweight)
- City and hospital tier wise average BMI and HBA1C tracking
- Diabetes status breakdown (Normal 47%, Diabetes 34%, Prediabetes 19%)
- Interactive slicers: Hospital Tier, City Tier, Weight Status, Diabetes Status

## Tools & Technologies
- Microsoft Excel (Power Query, Power Pivot, Pivot Tables, Pivot Charts, Slicers)
- Data Cleaning & Aggregation
- GitHub (Version Control)

## Key Insights
- Smokers incur ~4x higher average charges ($32,864 vs $8,394)
- Obesity is the dominant weight category among heart patients (1,221 cases)
- Tier-3 hospitals have highest average charges ($11.1M) vs Tier-1 ($9.5M)
- 53% of patients are diabetic or prediabetic
